Interpolación de Lagrange vs. Newton
Tarea 1 Unidad 5
Metodos Numericos


Descripción

Proyecto desarrollado en Java para implementar y comparar dos métodos numéricos de interpolación polinomial: Lagrange y Diferencias Divididas de Newton.

Objetivo

Aplicar ambos métodos para calcular valores interpolados y comprobar la equivalencia de sus resultados.

Métodos implementados

- Lagrange: Calcula el polinomio interpolador mediante polinomios base.
- Newton: Construye el polinomio utilizando diferencias divididas y sus respectivos coeficientes.

Ejecución

1. Clonar o descargar este repositorio.
2. Abrir el proyecto en un IDE compatible con Java.
3. Ejecutar la clase principal.
4. Consultar los resultados en la consola.

Resultados

El programa muestra los valores obtenidos mediante ambos métodos y la matriz de diferencias divididas de Newton, permitiendo comparar sus resultados.
